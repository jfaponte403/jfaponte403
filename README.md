## <picture><img src="https://github.com/7oSkaaa/7oSkaaa/blob/main/Images/about_me.gif?raw=true" width=50px></picture> About Me

Backend developer based in Bogotá, Colombia with **3+ years of experience** building production systems in **Python (FastAPI) on AWS**. I specialize in serverless and event-driven architectures, API design, data modeling, and secure authentication, with infrastructure managed as code through Terraform.

- 💼 **Full-Stack Developer (Backend-focused)** at Llyner S.A.S
- ☁️ Serverless & event-driven backends: **Lambda, API Gateway, SQS, DynamoDB**
- 🔐 Secure APIs with **OAuth 2.0, JWT, Amazon Cognito** and Lambda Authorizers
- 🏗️ Clean architecture, SOLID, and automated testing enforced in CI/CD
- 🤖 AI-assisted development with **Claude Code**: spec-driven workflows using MCP servers, custom skills and `CLAUDE.md` context, while owning code review and quality
- 🎓 Telematics Engineering student at Universidad Distrital Francisco José de Caldas
- 🗣️ Spanish (native) · English (B2)
